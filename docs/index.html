How Multiplayer Works (2–4 Players)
EASY SETUP

One player hosts the city and everyone else joins with a short invite code or link. Each player controls their own Boss and fights for turf.

1 · Host the game

Pick Host Multiplayer, enter a Boss alias and press Create Room. Choose the map, speed and income, then press Launch Turf War when everyone is in.

2 · Invite your friends

Press Copy Invitation and share the code or link. Friends can open the link straight away, or paste the code into the Join screen.

3 · Join a game

Pick Join Multiplayer, enter a Boss alias, paste the invite code or link and press Connect. Wait in the lobby until the host launches.

  • • Empty seats are filled by AI, so you can start with fewer friends.
  • • The host is the referee: their map and match settings are used for everyone.
  • • Keep the host's tab visible. Background tabs slow the game down.
  • • Everyone needs the same game version to connect.

Hire is one-time; upkeep is paid every hour. Rank is the shared structure; each syndicate uses its own title in-game (Don, Pakhan, Sottocapo …). Caps scale with the city grid: Underbosses ×1, Captains ×2, Soldiers ×10 (15×15 allows 15 / 30 / 150). Minimums are 1 / 2 / 10. Lower each rank's ceiling in Crew Limits before launch, then set your own target in Crew Management with MIN / − / + / MAX. Corruption reduces income by 1% for every 10 neighborhoods and every 25 living units; the Crew Management totals show the Turf, Crew and total percentages. Armor absorbs damage before HP. Bosses and Underbosses carry the pistol (50-80 at up to 600px, 10-round magazine, 4s reload); Captains and Soldiers are knife-only. Capture points are per tick and stack: Boss/Underboss 1, Captain 0.5, Soldier 0.2. You cannot capture enemy turf while any enemy unit is on it; neutral turf never resists. HP regenerates only on your own turf while not taking damage: Boss 5, Underboss 4, Captain 2, Soldier 1 per second.
